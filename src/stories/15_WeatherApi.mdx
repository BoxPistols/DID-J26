### 1-9. 使用例

```tsx
import {
  fetchPrefectureWeather,
  findNearestPrefecture,
  getWeatherDescription
} from 'japan-drone-map'

// 地図クリック時
async function handleMapClick(lat: number, lng: number) {
  // 最寄りの都道府県を検索
  const prefecture = findNearestPrefecture(lat, lng)

  // 天気データ取得
  const weather = await fetchPrefectureWeather(prefecture.lat, prefecture.lng)

  // 天気アイコン・ラベル取得
  const { icon, label } = getWeatherDescription(weather.current.weather_code)

  console.log(`${prefecture.name}: ${icon} ${weather.current.temperature_2m}°C ${label}`)
}
```

## 3. ドローン運用安全システム (JMA Mesh)

飛行可否を判定するための気象・通信・時間データを統合したシステム。

### 3-1. 概要

```
目的: ドローン飛行の安全性判定
データソース:
  - 気象庁メッシュAPI（風速・降水確率）
  - Sunrise-Sunset.org（民間薄明時間）
  - LTEカバレッジ（通信確保）
```

### 3-2. ファイル構成

```
src/lib/
├── services/
│   ├── jmaMesh.ts           # 気象庁メッシュAPI
│   ├── sunriseSunset.ts     # 日没時刻API
│   └── networkCoverage.ts   # LTEカバレッジ
├── hooks/
│   ├── useWeatherMesh.ts    # 気象データフック
│   ├── useFlightWindow.ts   # 飛行可能時間帯
│   ├── useNetworkCoverage.ts # 通信状況
│   └── useOperationSafety.ts # 統合安全判定
└── utils/
    └── meshCodeConverter.ts  # メッシュコード変換
```

### 3-3. 飛行安全判定ルール

```typescript
// useOperationSafety の判定ロジック
canFly = true
  && windSpeed < 10      // 風速10m/s未満
```

### 3-6. useOperationSafety フック

```typescript
import { useOperationSafety, getSafetyLevelColor } from 'japan-drone-map'

function FlightSafetyCheck({ lat, lng, meshCode }) {
  const safety = useOperationSafety(lat, lng, meshCode)

  if (safety.loading) return <div>安全確認中...</div>

  return (
    <div style={{ backgroundColor: getSafetyLevelColor(safety.safetyLevel) }}>
      {safety.canFly ? (
        <span>[OK] 飛行可能</span>
      ) : (
        <div>
          <span>[NG] 飛行不可</span>
          <ul>
            {safety.reasons.map((r, i) => (
              <li key={i}>{r.message}</li>
            ))}
          </ul>
        </div>
      )}
    </div>
  )
}
```

## 5. 日没時刻・民間薄明 (Sunrise-Sunset)

### 5-1. API仕様

```
API: Sunrise-Sunset.org
URL: https://api.sunrise-sunset.org/json
料金: 完全無料
認証: 不要
```

### 5-2. useFlightWindow フック

```typescript
import { useFlightWindow } from 'japan-drone-map'

function DaylightInfo({ lat, lng }) {
  const flight = useFlightWindow(lat, lng)

  return (
    <div>
      <p>日の出: {flight.sunrise?.toLocaleTimeString()}</p>
      <p>日没: {flight.sunset?.toLocaleTimeString()}</p>
      <p>民間薄明終了: {flight.civilTwilightEnd?.toLocaleTimeString()}</p>
      <p>飛行可能: {flight.flightAllowedNow ? 'はい' : 'いいえ'}</p>
      {flight.minutesRemaining && (
        <p>残り時間: {flight.minutesRemaining}分</p>
      )}
    </div>
  )
}
```

### 5-3. MLIT規制

```
■ 無人航空機の飛行禁止時間帯
- 民間薄明時間終了後（夜間）のドローン飛行禁止
- 例外: 照明設備のあるエリアで許可申請された場合のみ

■ 民間薄明時間（Civil Twilight）とは
- 日没後、太陽の中心が地平線下6°に達するまでの時間
- この間は自然光で十分な視認性がある
```
