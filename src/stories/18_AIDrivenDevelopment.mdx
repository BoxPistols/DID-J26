# AI駆動開発ガイド

**AI駆動開発の経験がない方**を対象に、このプロジェクトでどのようにAIを活用しているかを丁寧に説明します。

---

## AI駆動開発とは？

### 従来の開発

```text
開発者 → コードを書く → 動作確認 → デバッグ
         ↑
         すべて手作業
```

**課題**:
- コードを一から書くのに時間がかかる
- バグ修正に時間がかかる
- ドキュメント作成が後回しになる

### AI駆動開発

```text
開発者 → AIに指示 → AIがコード生成 → レビュー → 調整
         ↓
         自然言語で会話
```

**メリット**:
- ✅ コード作成が高速化（3〜5倍速い）
- ✅ 単純作業はAIに任せて創造的な部分に集中
- ✅ ドキュメントも同時に生成できる
- ✅ ベストプラクティスを自動適用

### 誤解を解く

❌ **誤解**: AIが全部やってくれるから開発者は不要
✅ **現実**: AIは**アシスタント**。最終判断は人間が行う

❌ **誤解**: AIを使うのはズル
✅ **現実**: 電卓を使うのと同じ。**道具を賢く使うスキル**

❌ **誤解**: AI駆動開発は難しい
✅ **現実**: 日本語で会話するだけ。**プログラミングより簡単**

## このプロジェクトで使っているAIツール

### 1. GitHub Copilot 🤖

**何をするツール？**
エディタ内でコードを自動補完してくれる「ペアプログラマー」

**できること**:
- コメントを書くと、自動的にコードを生成
- 関数名を書くと、実装を自動提案
- テストコードを自動生成

**使うタイミング**:
```typescript
// 例：コメントを書くだけでコードが生成される
// 緯度経度から距離を計算する関数
function calculateDistance(lat1, lon1, lat2, lon2) {
  // ← ここでTabを押すと、Copilotが実装を提案
}
```

**料金**: 月額 $10（学生・OSS開発者は無料）

### 2. Claude Code（このプロジェクトの主力） 🎯

**何をするツール？**
ターミナルで対話しながら、ファイル編集・実行・デバッグを全自動でやってくれるAIアシスタント

**できること**:
- 「〇〇機能を追加して」→ 複数ファイルを自動編集
- 「このエラー修正して」→ 原因特定して修正
- 「テスト書いて」→ テストコードを自動生成
- 「PRを作成して」→ GitHub PRまで自動作成

**使用例**:
```text
# ターミナルで対話
$ claude

You: 天気予報APIを追加してください

Claude: 了解しました。以下の手順で実装します：
1. API接続コードを作成
2. UIコンポーネントを追加
3. テストを書く
4. ドキュメントを更新

[自動的にファイルを編集開始...]
```

**料金**: 月額 $20（Proプラン）

**このプロジェクトでの役割**:
- ⭐ **メイン開発ツール**
- 大規模なリファクタリング
- 複数ファイルにまたがる機能追加
- バグ修正
- ドキュメント整備

### 3. Gemini CLI 🔍

**何をするツール？**
GitHub上でPRやIssueに対してAIレビューを自動実行

**できること**:
- PRを開くと自動でコードレビュー
- バグや改善点を指摘
- セキュリティ問題を検出

**使い方**:
```text
# PRのコメント欄で
@gemini-cli /review
```

**料金**: 無料枠あり（クォータ制限あり）

**このプロジェクトでの役割**:
- コードレビューの自動化
- 品質チェック
- セキュリティ監査

### 4. CodeRabbit 🐰

**何をするツール？**
GitHub PRに自動でレビューコメントをつけるAIレビュアー

**できること**:
- コードの問題点を自動指摘
- ベストプラクティス違反を検出
- 改善提案を具体的に提示

**料金**: オープンソースは無料

**このプロジェクトでの役割**:
- セカンドオピニオン
- リンター・フォーマッター的な細かいチェック

## AIとの対話のコツ

### ❌ 悪い例

```text
You: 動かない
```

→ AIは何を修正すればいいかわからない

### ✅ 良い例

```text
You: 天気マップコンポーネントで以下のエラーが出ます：
TypeError: Cannot read property 'temperature' of undefined

原因を調査して修正してください。
```

→ 具体的なエラーメッセージがあるので、AIが原因を特定できる

### 上手に指示するポイント

#### 1. 具体的に伝える

❌ 「きれいにして」
✅ 「グラスモーフィズムデザインにして、背景を半透明にしてください」

#### 2. 制約条件を伝える

❌ 「天気APIを追加して」
✅ 「Open-Meteo APIを使って天気を取得してください。無料枠で動くようにお願いします」

#### 3. 期待する結果を伝える

❌ 「地図を改善して」
✅ 「地図の初期表示を東京中心、ズーム12にしてください」

#### 4. エラーメッセージは全文コピペ

```text
You: 以下のエラーが出ています：

[エラーメッセージ全文をコピペ]

修正してください
```

#### 5. 段階的に進める

一度に全部やろうとせず、小さく分割：

```text
You: 以下の順番で進めてください：
1. まずAPIを接続
2. 動作確認
3. UIを実装
4. テストを追加
```

## よくある質問

### Q1: AIに頼りすぎるとスキルが落ちませんか？

**A**: 正しく使えば逆にスキルアップします。

- ❌ **悪い使い方**: AIが生成したコードをそのままコピペ
- ✅ **良い使い方**: AIの提案を理解してから採用

**例**:
```typescript
// AIが提案したコード
const result = data.reduce((acc, cur) => acc + cur.value, 0)

// 理解する：
// reduceで配列の合計を計算している
// accは累積値、curは現在の要素
// 初期値は0

// 理解したら自分の言葉でコメント追加
// 各要素のvalueを合計
const result = data.reduce((acc, cur) => acc + cur.value, 0)
```

### Q2: AIが間違ったコードを生成することはありますか？

**A**: あります。だから**必ずレビューが必要**です。

**対策**:
1. AIが生成したコードは必ず動作確認
2. テストコードを書く（これもAIに書かせる）
3. 複数のAIツールでチェック（Gemini CLI、CodeRabbit）

### Q3: AI駆動開発を始めるのに何が必要ですか？

**A**: 最低限これだけ：

**必須**:
- GitHub Copilot（月額$10、学生無料）

**推奨**:
- Claude Code（月額$20）

**無料で使えるもの**:
- Gemini CLI（無料枠あり）
- CodeRabbit（OSS無料）

**初期投資**: 月額$30程度
**時間短縮効果**: 開発時間が1/3〜1/5に

### Q4: プログラミング初心者でも使えますか？

**A**: 使えます。むしろ初心者にこそおすすめ。

**理由**:
- 正しい書き方をAIが教えてくれる
- ベストプラクティスを自動適用
- エラーの原因をわかりやすく説明

**学習曲線**:
```text
従来:
  理解度
    ↑      /
    |    /
    |  /
    |/________→ 時間
    急な坂（挫折しやすい）

AI駆動:
  理解度
    ↑    ____/
    |  /
    | /
    |/________→ 時間
    緩やかな坂（継続しやすい）
```

### Q5: このプロジェクトに参加するのにAI必須ですか？

**A**: 必須ではありませんが、**強く推奨**します。

**AI なしでも参加可能**:
- 通常のGit/GitHubワークフロー
- 手動でコード作成・レビュー

**AI ありだと**:
- 開発速度が3〜5倍速い
- ドキュメントも自動生成
- コードレビューが自動
