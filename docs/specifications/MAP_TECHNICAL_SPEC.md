## 地図タイルの種類

このアプリケーションは複数の地図タイルプロバイダーに対応しています。

### サポートしている地図タイル

| 地図 | プロバイダ | 特徴 | 用途 |
|------|-----------|------|------|
| **標準** | OpenStreetMap (OSM) | カラフルで詳細。世界中で利用可能 | 一般的な地図表示 |
| **地理院地図** | 国土地理院 (GSI) | 日本の公式地理データ。最も正確 | 正確な位置情報が必要な場合 |
| **淡色地図** | 国土地理院 (GSI) | シンプルで見やすい | オーバーレイの背景に最適 |
| **航空写真** | 国土地理院 (GSI) | 衛星画像 | 地形や施設の確認 |
| **メルカトル図法** | 国土地理院 (GSI) | 明示的にメルカトル投影を指定 | Web地図標準 |

### タイルの技術仕様

**ラスタータイル**:
- フォーマット: PNG画像
- タイルサイズ: 256×256ピクセル
- 座標系: Web Mercator (EPSG:3857)

**ベクタータイル**:
- フォーマット: MapBox Vector Tiles (MVT) / Protobuf
- 座標系: Web Mercator (EPSG:3857)
- レンダリング: MapLibre GL JS

## 地図投影法

### メルカトル図法（Mercator Projection）

本アプリケーションでは、Web地図の業界標準である**メルカトル図法**を使用しています。

#### 技術的特徴

**数学的定義**:
```text
x = λ
y = ln(tan(π/4 + φ/2))

where:
  λ = 経度 (longitude)
  φ = 緯度 (latitude)
```

**特性**:
1. **等角投影（Conformal）**:
   - 小さな領域では角度が保存される
   - 航海や航空ナビゲーションに最適

2. **円筒図法（Cylindrical）**:
   - 地球を円筒に投影
   - 赤道が正確に表現される

3. **メリット**:
   - ✅ 直線が等角航路（loxodrome）を表す
   - ✅ 方位が正確
   - ✅ Web地図の標準仕様
   - ✅ タイル化に最適

4. **デメリット**:
   - ❌ 高緯度ほど面積が拡大
   - ❌ 極地方は表現できない（±85.05度が限界）
   - ❌ 距離は不正確（特に南北方向）

#### なぜメルカトル図法を採用？

**業界標準**:
- Google Maps、Apple Maps、OpenStreetMap など、世界中のWeb地図サービスが採用
- MapLibre GL JSもメルカトル図法を前提に設計

**技術的利点**:
- タイルベースの地図配信に最適化
- クライアントサイドレンダリングが高速
- ズームレベルとの相性が良い

**実装の互換性**:
- 既存の地図タイルプロバイダー（国土地理院、OSM等）がメルカトル図法のタイルを提供
- ライブラリとの統合が容易

## 座標系

### 使用している座標系

#### 1. WGS84（EPSG:4326）

**正式名称**: World Geodetic System 1984

**用途**:
- GPS座標
- GeoJSONデータ
- 地理的座標（緯度経度）

**座標範囲**:
```text
緯度（Latitude）:  -90° 〜 +90°
経度（Longitude）: -180° 〜 +180°
```

**東京駅の例**:
```text
緯度: 35.6812°
経度: 139.7671°
```

**特徴**:
- 地球楕円体に基づく測地座標系
- GPS衛星で使用
- 角度（度）で表現

#### 2. Web Mercator（EPSG:3857）

**正式名称**: WGS 84 / Pseudo-Mercator

**用途**:
- Web地図のタイル座標
- MapLibre GL JSの内部座標
- ラスタータイル・ベクタータイル

**座標範囲**:
```text
X: -20037508.34 〜 +20037508.34 (メートル)
Y: -20037508.34 〜 +20037508.34 (メートル)
```

**東京駅の例**:
```text
X: 15558098.63 (メートル)
Y: 4257179.75 (メートル)
```

**特徴**:
- メルカトル図法による平面直角座標
- 距離の単位はメートル
- ±85.05度の緯度範囲のみサポート（極地方は表示不可）

**別名**:
- Google Mercator
- Spherical Mercator
- EPSG:900913（"GOOGLE"を数字に見立てた番号）

### 座標変換

アプリケーション内での座標変換：

```typescript
// GeoJSON（WGS84）→ Web Mercator
const projected = maplibregl.MercatorCoordinate.fromLngLat([lon, lat])

// Web Mercator → WGS84
const lngLat = projected.toLngLat()
```

## データソース

### レイヤー別データソース一覧

| レイヤー | ソース | 形式 | 座標系 | 更新頻度 |
|----------|--------|------|--------|---------|
| **雨雲レーダー** | RainViewer API | ラスタータイル | EPSG:3857 | 5分ごと |
| **天気予報** | Open-Meteo API | JSON | WGS84 | 1時間ごと |
| **人口集中地区（DID）** | e-Stat | GeoJSON | WGS84 | 5年ごと（国勢調査） |
| **空港敷地（C28）** | 国土数値情報 | GeoJSON | WGS84 | 不定期 |
| **空港周辺空域** | 国土地理院 | ラスタータイル | EPSG:3857 | 不定期 |
| **地理院地図タイル** | 国土地理院 | ラスタータイル | EPSG:3857 | 随時 |
| **陰影起伏・標高図** | 国土地理院 | ラスタータイル | EPSG:3857 | 固定 |
| **有人機発着地** | OSM/自治体 | GeoJSON | WGS84 | 手動更新 |
| **駐屯地・基地** | OSM/自治体 | GeoJSON | WGS84 | 手動更新 |
| **消防署** | OSM/自治体 | GeoJSON | WGS84 | 手動更新 |
| **医療機関** | OSM/自治体 | GeoJSON | WGS84 | 手動更新 |

### データ取得方法

#### e-Stat（DIDデータ）

**API仕様**:
- エンドポイント: `https://www.e-stat.go.jp/gis/statmap-search`
- 形式: Shapefile → GeoJSON変換
- 座標系変換: JGD2011（EPSG:6668）→ WGS84（EPSG:4326）

**変換ツール**:
```bash
mapshaper input.shp -proj EPSG:4326 -o output.geojson
```

#### 国土数値情報（空港データ）

**データコード**: C28（空港データ）
**URL**: https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-P13.html
**形式**: Shapefile → GeoJSON変換
**座標系**: JGD2011 → WGS84

#### 国土地理院（タイル）

**タイルURL形式**:
```text
https://cyberjapandata.gsi.go.jp/xyz/{tileset}/{z}/{x}/{y}.{ext}

where:
  {tileset} = タイルセット名（例: std, pale, ort）
  {z} = ズームレベル（0-18）
  {x} = タイルX座標
  {y} = タイルY座標
  {ext} = ファイル拡張子（png, jpg等）
```

**例（地理院標準地図）**:
```text
https://cyberjapandata.gsi.go.jp/xyz/std/12/3638/1612.png
```

### ズームレベルと縮尺の関係

| ズームレベル | 赤道上の縮尺 | 表示範囲の目安 |
|------------|------------|--------------|
| 0 | 1:500,000,000 | 地球全体 |
| 5 | 1:15,000,000 | 国全体 |
| 10 | 1:500,000 | 都道府県 |
| 12 | 1:125,000 | 市区町村 |
| 15 | 1:15,000 | 町内・街区 |
| 18 | 1:2,000 | 建物 |

**注意**: メルカトル図法のため、高緯度ほど実際の縮尺は大きくなります。

## パフォーマンス最適化

### タイルキャッシュ

**ブラウザキャッシュ**:
- タイルはブラウザにキャッシュされる
- Cache-Controlヘッダーに基づく

**MapLibre GL JSのキャッシュ**:
- メモリキャッシュ: 最近使用したタイル
- デフォルトサイズ: 50MB

### データの遅延読み込み

**ビューポートベース読み込み**:
- 表示範囲内のデータのみ読み込み
- スクロール・ズーム時に動的に追加読み込み

**地方別DIDデータ**:
- 全国一括ではなく、地方ごとに分割
- 必要な地域のみ読み込むことでメモリ節約

### 空間インデックス

**RBush空間インデックス**:
- 衝突検出の高速化
- O(log n) の検索速度
- バウンディングボックスベースの検索

## ブラウザ互換性

### 必要な機能

**WebGL対応**:
- MapLibre GL JSはWebGLを必須とする
- WebGL非対応ブラウザでは動作しない

**対応ブラウザ**:
- Chrome 79+
- Firefox 78+
- Safari 13+
- Edge 79+

**非対応**:
- Internet Explorer（すべてのバージョン）
- Opera Mini

### フォールバック

WebGL非対応の場合、以下の代替案：
1. 静的地図画像の表示
2. Leaflet.jsへのフォールバック（ラスタータイルのみ）
